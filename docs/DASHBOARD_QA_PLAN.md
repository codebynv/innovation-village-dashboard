# Dashboard QA Plan

- Verify loading, success, empty, and error states.
- Compare displayed totals with a small known dataset.
- Check filters individually and in combination.
- Confirm timestamps and timezone labels are consistent.
- Verify restricted data is not exposed to unauthorized users.
- Test narrow screens and keyboard navigation.
- Confirm stale data is not presented as a fresh result.

Record the dataset and checks used when reporting QA results.
